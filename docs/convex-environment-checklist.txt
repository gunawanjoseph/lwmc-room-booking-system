# JOTFORM FIELD-MAP TIMING MODES
#
# Same-day split fields:
# {"requesterName":"3","requesterEmail":"4","room":"5","date":"6","startTime":"7","endTime":"8"}
#
# Split fields that can cross midnight:
# {"requesterName":"3","requesterEmail":"4","room":"5","date":"6","startTime":"7","endDate":"8","endTime":"9"}
#
# Complete date-time fields:
# {"requesterName":"3","requesterEmail":"4","room":"5","start":"6","end":"7"}
#
# Calendar title and recurrence fields (example qids only):
# {"requesterName":"3","requesterEmail":"4","room":"5","eventName":"6","purpose":"7","ministry":"8","recurrence":"9","recurrenceCount":"10","recurrenceUntil":"11","date":"12","startTime":"13","endTime":"14"}
#
# Core questions use stable qids. Reordering or relabeling is safe. Deleting
# and recreating a mapped core question can change its qid and needs remapping.
# Non-core response questions require no mapping: Convex stores bounded text
# (including explicit blanks) keyed by qid, and /sheet renders the columns.
# Snapshot caps: 80 fields, 4,000 characters per answer, and 50,000 answer
# characters total. Capped submissions are marked in /sheet and system logs.
#
# Supported recurrence choices:
#   none
#   daily
#   weekly on the same day
#   monthly on the same day (same ordinal weekday, such as third Friday)
#   monthly on the same date (same numerical date)
# Count includes the first occurrence. repeat-until is inclusive. If both are
# supplied, the earlier bound wins. Monthly rules skip nonexistent dates or
# ordinal weekdays. See docs/GOOGLE_CALENDAR_SETUP.md for the full semantics.
